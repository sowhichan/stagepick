# StagePick v2를 Vercel에 올리기

## 배포 전 확인

- `index.html`이 프로젝트 최상단에 있고, `css/`, `js/`, `assets/` 디렉터리가 함께 있어야 합니다.
- 시연용 공연은 실제 예약 가능 상품이 아닙니다. 가상 공연 표시와 예약 버튼 비활성화 상태를 유지하세요.
- 브라우저 등록 정보는 서버에 저장되지 않으므로, Vercel 배포 뒤에도 방문자 간에 공유되지 않습니다.

## 방법 A: GitHub + Vercel (권장)

1. 압축을 풀고 `stagepick-v2` 폴더의 **내용 전체**를 새 GitHub 저장소에 업로드합니다. GitHub 저장소의 최상위에 `index.html`이 놓이게 합니다.
2. [Vercel](https://vercel.com/)에 로그인하고 **Add New → Project**로 이동합니다.
3. GitHub에서 해당 저장소를 선택하고 **Import**합니다.
4. Framework Preset은 **Other**, Root Directory는 저장소 루트(`./`)로 설정합니다.
5. 빌드 명령은 필요 없으며 Output Directory는 비워 두거나 기본 설정을 사용합니다. **Deploy**합니다.
6. 제공된 `*.vercel.app` 주소에서 취향 매칭·공연 필터·등록 시연·모바일 화면을 확인합니다.
7. 이후 GitHub에 수정 사항을 push하면 Vercel이 다시 배포합니다.

## 방법 B: Vercel CLI

Vercel CLI가 설치된 개발 환경에서 프로젝트 폴더로 이동하여 `vercel`(미리보기) 또는 `vercel --prod`(정식)를 실행할 수 있습니다. 실제 대상 계정·프로젝트를 확인한 뒤 진행하세요.

## 정식 공개 직전 체크리스트

- [ ] 실제 아티스트 정보 및 연결된 Spotify URL 최신 상태 확인
- [ ] 가상의 공연 일정·가격·예매 불가 안내 명확히 표시
- [ ] 외부 링크가 사용자가 검증한 대상인지 확인
- [ ] 데스크톱/모바일에서 직접 취향 입력, 검색, 저장, 등록 테스트
- [ ] 브라우저 저장은 공유 DB가 아니라는 점 명시
- [ ] 공개한 사이트에 개인정보나 실사용 비밀키가 포함되지 않도록 확인

## 현재 제공 범위

이 폴더는 **배포할 수 있도록 준비된 소스코드**입니다. 이 기록을 작성하는 시점에 Vercel에 실제 사이트를 배포한 것은 아닙니다. 실제 배포 URL은 계정과 저장소를 연결해 배포한 뒤에 생성됩니다.
