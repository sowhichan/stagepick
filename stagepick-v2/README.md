# StagePick v2 — 음악을 발견하고, 무대를 만나다

AX 개인 프로젝트를 위한 **정적 웹사이트 / Vercel 배포 준비본**. 기존 `StagePick_Level2_Prototype.html`을 기반으로 추천 엔진, 아티스트 탐색, 공연 탐색, 관계자 직접 등록, 모바일 UX를 개선했습니다.

## 빠른 실행

- `index.html`을 브라우저에서 열면 됩니다. 일부 브라우저 보안 환경에서는 로컬 파일 접근이 제한될 수 있습니다.
- 권장: 폴더에서 `python -m http.server 8000`을 실행한 다음 `http://localhost:8000` 접속.
- 의존성 및 API 키가 필요하지 않습니다.
- 단위 테스트: Node.js 설치 후 `node tests/engine.test.js`.

## 구현 기능

1. **취향 추천 엔진**: 장르·분위기·좋아하는 아티스트/곡·새로운 음악 탐색 정도를 반영해 아티스트 최대 3팀 추천. 관련 공연이 있으면 지역·날짜·예산 적합성을 적용하고, 없으면 음악적으로 가까운 다른 아티스트의 공연을 제시합니다.
2. **아티스트 디렉터리**: 이름·장르·곡명 검색, 장르 필터, 이름/장르 정렬, 아티스트 소개 및 유사 아티스트 모달, Spotify 임베드 재생 요청.
3. **공연 탐색**: 공연명·아티스트·장소 검색, 지역·예산·주말 필터, 하트로 저장한 공연만 보기.
4. **관계자 등록**: 3단계(아티스트 → 공연 → 확인) 입력, 수정/삭제, 브라우저 저장, JSON 내보내기·가져오기. 등록 정보는 **다른 사용자에게 공유되지 않습니다**.
5. **UX·디자인**: 정리된 시각 계층, 브랜드 그래픽, 반응형 카드와 모바일 메뉴, 키보드 탐색 및 기본 상태 안내.

## 데이터 사용 및 중요한 제약

- 초기 카탈로그는 기존 프로토타입에 있던 **실제 아티스트 12팀과 Spotify 참고 URL**입니다. 링크의 최신 재생 가능 여부를 이 프로젝트가 확인하지는 않습니다.
- 초기 공연 9개는 **모두 가상의 시연용 공연**이며, 실제 공연 일정·예약 재고가 아닙니다. 가상의 공연은 예약 버튼이 비활성화됩니다.
- 이용자가 등록한 공연/링크는 **직접 등록 · 미검증**으로 표시됩니다. 유효한 HTTPS 주소만 허용해도 그 링크의 내용/운영자가 실제인지 자동으로 증명하는 것은 아닙니다.
- 추천은 JavaScript 기반 **규칙·점수 계산**으로 실행되며 실시간 LLM 호출이 아닙니다. AI 추천 흐름은 별도 ChatGPT 작업으로 설계·검증합니다.
- 공연 데이터는 브라우저 로컬에서만 저장합니다. 실제 관계자별 계정·공동 공연 등록·공식 검수·예매와 결제에는 백엔드가 필요합니다.
- 외부 플랫폼의 음원/공연 포스터 저작권을 침해하지 않기 위해 음원 파일이나 상업용 아티스트 사진은 직접 저장하지 않았습니다.

## 프로젝트 구조

```text
stagepick-v2/
├── index.html                 # 화면 구조
├── css/style.css              # 디자인 및 반응형 스타일
├── js/data.js                 # 초기 아티스트·시연용 공연 데이터
├── js/recommend.js            # 순수 추천·조건 검증 로직
├── js/app.js                  # UI·등록·저장·모달
├── assets/favicon.svg
├── tests/engine.test.js       # 독립 로직 검사
├── tests/browser_smoke.py     # 브라우저 UI 스모크 테스트용
├── vercel.json                # 정적 배포 기본 헤더
├── VERCEL_DEPLOY.md           # 배포 방법
└── QA.md                      # 검증 결과 및 남은 항목
```

## 다음 확장

- 실제 운영을 시도하려면 먼저 공연 정보 사용 허락·최신성 유지·검수 프로세스를 정해야 합니다.
- 여러 관계자가 등록한 데이터를 공유하려면 인증/권한/DB(예: Supabase)를 연결해야 합니다.
- 실시간 LLM 추천을 구현하려면 클라이언트에 비밀키를 넣지 말고 서버리스 API(예: Vercel Functions)에 모델 호출을 배치해야 합니다.
