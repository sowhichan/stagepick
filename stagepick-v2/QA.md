## 브라우저 환경의 제한

실제 사이트 URL 및 `file://` 경로로의 Chromium 접근이 실행 환경 정책에 의해 차단되어, HTML·CSS·JavaScript를 **브라우저에 직접 주입**해 화면을 검증했습니다. `localStorage`는 브라우저 내 메모리 스텁을 이용하여 입출력 흐름을 검사했습니다. 따라서 **배포 URL로 접속한 실제 네트워크 동작, 브라우저별 저장 지속성, 외부 Spotify 임베드 재생 및 공식 티켓 예매는 검증한 것으로 보지 않습니다.**

## 수동 확인이 필요한 항목

- [ ] Vercel Preview URL에서 JS·CSS·이미지 로딩
- [ ] 사용자 브라우저에서 실제 새로고침 시 저장 유지
- [ ] Spotify 링크 최신성 및 플레이어 재생 권한
- [ ] 링크 이동 시 주소 및 실제 주최자 일치 여부
- [ ] 실제 음악/공연 데이터로 추천 품질 검토
- [ ] 다양한 화면 크기와 브라우저 접근성 확인

시연용 공연을 공개 페이지에 실제 예정 공연처럼 표시하지 않습니다.
